# 🚀 Руководство по установке и запуску Telegram Auth & Shop Bot

Полнофункциональный бот для автоматизации продажи Telegram-аккаунтов, выдачи кодов авторизации покупателям, экспорта Tdata / .session, управления 2FA и прокси.

---

## 📋 Требования к системе
- **ОС:** Windows 10/11 или Linux (Ubuntu 20.04/22.04/24.04, Debian).
- **Python:** версия **3.10** или выше.

---

## ⚡ Быстрый запуск на Windows (в 1 клик)

1. **Распакуйте архив** с ботом в любую удобную папку (например, `C:\telegram_bot`).
2. Запустите файл **`START.bat`**:
   - При первом запуске он автоматически создаст файл конфигурации `.env` из шаблона.
3. Откройте созданный файл **`.env`** через Блокнот и укажите:
   - `BOT_TOKEN` — токен вашего бота (получить у [@BotFather](https://t.me/BotFather)).
   - `ADMIN_IDS` — ваш числовой Telegram ID (узнать можно в [@userinfobot](https://t.me/userinfobot)).
4. **Сохраните файл `.env`** и снова запустите **`START.bat`**.
   - Скрипт сам создаст виртуальное окружение, установит все библиотеки и запустит бота!

## 🐧 Установка и запуск на Linux / VDS / VPS (Ubuntu / Debian)

### 1. Обновление пакетов и установка Python
```bash
sudo apt update && sudo apt upgrade -y
sudo apt install -y python3 python3-pip python3-venv git
```

### 2. Загрузка бота на сервер
Перенесите папку с ботом на сервер (через SFTP/FileZilla или SCP) в директорию `/opt/telegram_bot` или `~/telegram_bot`.

```bash
cd ~/telegram_bot
```

### 3. Создание виртуального окружения и установка библиотек
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install --upgrade pip
pip install -r requirements.txt
```

### 4. Настройка файла .env
Скопируйте шаблон конфигурации:
```bash
cp .env.example .env
nano .env
```
Заполните параметры:
- `BOT_TOKEN=ВАШ_ТОКЕН_ОТ_BOTFATHER`
- `ADMIN_IDS=ВАШ_ТЕЛЕГРАМ_ID`

*(Нажмите `Ctrl + O`, затем `Enter` для сохранения, и `Ctrl + X` для выхода из nano)*.

### 5. Фоновый запуск (через systemd — рекомендуется)
Чтобы бот работал 24/7 и автоматически поднимался при перезагрузке сервера:

Создайте службу:
```bash
sudo nano /etc/systemd/system/tgbot.service
```

Вставьте следующее содержимое (замените `username` на имя вашего пользователя):
```ini
[Unit]
Description=Telegram Auth Bot
After=network.target

[Service]
Type=simple
User=root
WorkingDirectory=/root/telegram_bot
ExecStart=/root/telegram_bot/.venv/bin/python main.py
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
```

Активируйте и запустите:
```bash
sudo systemctl daemon-reload
sudo systemctl enable tgbot
sudo systemctl start tgbot
```

Проверить статус работы:
```bash
sudo systemctl status tgbot
```

Просмотр логов в реальном времени:
```bash
journalctl -u tgbot -f
```

## ⚙️ Описание параметров в .env

| Параметр | Описание | Обязательный? |
| :--- | :--- | :---: |
| `BOT_TOKEN` | Токен бота от @BotFather | **Да** |
| `ADMIN_IDS` | ID администраторов через запятую (например: `123456789,987654321`) | **Да** |
| `API_ID` | Telegram API ID (по умолчанию официальный Telegram Desktop: 2040) | Нет |
| `API_HASH` | Telegram API Hash (по умолчанию официальный) | Нет |
| `LOG_CHANNEL_ID` | ID канала для отправки логов действий (например `-1001234567890`) | Нет |
| `CODE_WAIT_TIMEOUT` | Время ожидания кода от Telegram в секундах (по умолчанию 90) | Нет |
| `WEB_PORT` | Порт встроенного веб-сервера (по умолчанию 8080) | Нет |

## 🎯 Основные функции бота

1. **Загрузка аккаунтов:**
   - Пофайлово `.session` (Telethon / MTProto).
   - Массовая загрузка через `.zip` архив с `.session` файлами.
   - Загрузка через архив `tdata` (автоматическая конвертация в `.session`).
   - Вход по номеру телефона / QR-коду прямо через интерфейс бота.

2. **Работа с покупателями:**
   - Генерация одноразовых ссылок на авторизацию для каждого аккаунта.
   - Покупатель получает удобное меню:
     - 📩 **Получить код авторизации** (из служебного чата 777000 в реальном времени).
     - 📁 **Скачать Tdata (ZIP)** — вход в один клик через Telegram Desktop.
     - 📄 **Скачать .session**.
     - 🚪 **Выйти ботом с аккаунта** — бот удаляет сессию у себя, сохраняя сессию покупателя активной.
     - ❓ **Интерактивный FAQ** с инструкциями по всем способам входа.

3. **Защита аккаунтов (Anti-Freeze):**
   - Бот имитирует официальный Telegram Desktop (Windows 11).
   - Полное отключение опасных команд завершения сессий со стороны сервера — ваши аккаунты не слетают и не морозится при входе.

4. **Менеджер Прокси:**
   - Поддержка SOCKS5, HTTP, HTTPS с авторизацией по логину и паролю.
   - Форматы: `ip:port:user:pass`, `protocol://user:pass@ip:port` и др.
   - Автоматическая проверка доступности и пинга каждого прокси.

5. **Управление профилем аккаунта:**
   - Просмотр диалогов и чатов.
   - Смена имени, фамилии, юзернейма.
   - Установка и изменение 2FA облачного пароля.
   - Привязка и удаление Email.
