# 🤖 Telegram Auth & Shop Bot

Мощный Telegram бот для автоматизации магазина аккаунтов Telegram, выдачи кодов подтверждения, конвертации Tdata / .session и управления аккаунтами.

## ✨ Ключевые возможности

- 📲 **Многоформатная загрузка аккаунтов:** `.session`, `tdata.zip`, массовые ZIP-архивы, QR-код, вход по SMS/коду.
- 🔑 **Авто-выдача для покупателей:** отправка кодов подтверждения из Telegram 777000 в реальном времени.
- 📁 **Конвертер TData:** экспорт рабочего Telegram Desktop tdata архива из любой сессии.
- 🛡️ **Anti-Freeze система:** использование актуальных Desktop сигнатур для предотвращения блокировок и слётов сессий.
- 🚪 **Безопасный выход:** покупатель может безопасно отключить бота без закрытия своих активных сессий на устройстве.
- 📡 **Встроенный прокси-менеджер:** поддержка SOCKS5/HTTP/HTTPS с авторизацией, проверка валидности и пинга.
- ⚙️ **Управление аккаунтами:** смена имени, фамилии, 2FA пароля, Email, просмотр диалогов.
- ❓ **Интерактивный FAQ:** пошаговые инструкции прямо в интерфейсе бота для покупателей.

## 🚀 Быстрый старт

Подробная инструкция находится в файле: [ИНСТРУКЦИЯ_ПО_УСТАНОВКЕ.md](ИНСТРУКЦИЯ_ПО_УСТАНОВКЕ.md)

### Windows
1. Скопируйте `.env.example` в `.env` и укажите ваш `BOT_TOKEN` и `ADMIN_IDS`.
2. Запустите `START.bat`.

### Linux
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
# отредактируйте .env
python3 main.py
```
